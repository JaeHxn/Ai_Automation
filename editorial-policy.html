편집 원칙

이 페이지는 콘텐츠 품질 기준과 정정 절차를 투명하게 공개하기 위해 운영됩니다.

최종 업데이트: 2026-02-19 (KST)

핵심 원칙

고유 콘텐츠 우선

모든 글은 사이트 운영팀이 직접 작성·편집하며, 외부 글 복제·대량 재가공을 지양합니다.

사용자 가치 중심

광고 노출 목적이 아니라 사용자가 실제로 실행 가능한 정보(절차, 체크리스트, 실패 보정)를 우선 제공합니다.

투명한 책임

작성일, 검토일, 수정 기준, 문의 채널을 공개해 콘텐츠 책임 경로를 명확히 합니다.

작성 및 검토 프로세스

  1. 주제 선정: 사용자 질문, 반복 오류 제보, 검색 수요를 기준으로 주제를 선정합니다.
  2. 초안 작성: 문제 배경, 점검 질문, 실행 절차, 실패 패턴, 체크리스트 구조로 초안을 작성합니다.
  3. 품질 점검: 과장 표현, 오해 가능 문구, 근거 없는 단정, 광고성 문구를 제거합니다.
  4. 출판 후 점검: 내부 링크/메타데이터/오탈자를 확인하고 최소 분기 1회 재검토합니다.

정정 정책

  • 사실 오류 또는 오해 소지가 확인되면 해당 문장을 우선 수정하고, 필요 시 문단 전체를 재작성합니다.
  • 핵심 의미가 바뀌는 수정은 검토일을 갱신하고 정책 페이지 또는 글 본문에 반영합니다.
  • 정정 요청은 문의 페이지로 접수되며, 확인 가능한 범위에서 처리 결과를 회신합니다.

광고·이해상충 고지

  • 사이트는 광고 코드(AdSense)를 사용할 수 있으나, 광고 유무와 관계없이 본문 정보 품질 기준은 동일하게 적용됩니다.
  • 특정 금융상품 매수·매도·가입을 직접 권유하지 않습니다.
  • 본문은 일반 정보 제공 목적이며, 개인 재무 상황에 따라 전문가 상담이 필요할 수 있습니다.
